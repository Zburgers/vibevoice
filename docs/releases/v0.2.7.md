# VibeVoice 0.2.7

## Stabilization

- Hardened renderer state refreshes so late responses cannot replace newer visible content.
- Added regression coverage for repeated state transitions and pill expand/collapse behavior.
- Replaced numeric update checks with validated SemVer precedence, including prereleases, build metadata, `v` prefixes, and malformed tags.
- Added a redacted diagnostics report that excludes transcripts, history, clipboard data, project vocabulary, and raw updater errors.
- Split main and pill capabilities, removed `core:default`, added caller-window authorization, and enabled a restrictive packaged CSP.
- Added native resize cursor handling for all eight edges and corners with CSS fallback.

## Verification

The branch includes frontend Vitest/jsdom coverage and Rust unit coverage. Full packaged Linux recording-cycle and manual eight-cursor verification remain release-gate checks and must be recorded before publication.
