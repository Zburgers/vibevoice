# VibeVoice 0.2.7

## Change hierarchy

### Reliability and UX

- **#15 — UI text and icons disappear after transcription:** stale renderer refreshes can no longer overwrite newer state; async listener registration is cleaned up safely; repeated pill transitions have regression coverage.
- **Pill HUD edge/corner overflow:** expansion now chooses a safe monitor work area, moves before resizing, reconciles against native outer dimensions, and ignores stale layout requests.
- **Resize cursor defect:** all eight resize edges/corners set native cursor icons with CSS fallback.
- **Transactional insertion timeout cleanup:** paste helpers are bounded and reaped; insertion snapshots/restores the previous clipboard, serializes clipboard mutations, records structured outcomes, and keeps legacy history readable.
- **Linux pill layout:** collapsed pill controls stay adjacent when the transparent Linux host window is larger than its logical content size.
- **Linux recording diagnostics:** zero-frame WAV captures fail with an actionable microphone/audio-service error before Whisper runs.

### Updates and diagnostics

- **#34 — SemVer precedence for updater fallback:** validated SemVer comparison handles prereleases, build metadata, `v` prefixes, and malformed values fail closed.
- **#8 — Copy diagnostics report:** adds a typed, categorized, redacted report that excludes transcripts, history, clipboard text, vocabulary, and raw errors.

### Security and packaging

- **#33 — CSP and pill capability isolation:** separates `main` and `pill` capabilities, removes `core:default`, authorizes commands by caller window, and configures packaged CSP.
- Restores the narrowly scoped event-listener permissions required by both windows for live state and meter updates.
- Updates application, Tauri, and release metadata to `0.2.7`, with frontend and Rust regression coverage.

## Stabilization

- Hardened renderer state refreshes so late responses cannot replace newer visible content.
- Added regression coverage for repeated state transitions and pill expand/collapse behavior.
- Replaced numeric update checks with validated SemVer precedence, including prereleases, build metadata, `v` prefixes, and malformed tags.
- Added a redacted diagnostics report that excludes transcripts, history, clipboard data, project vocabulary, and raw updater errors.
- Split main and pill capabilities, removed `core:default`, added caller-window authorization, and enabled a restrictive packaged CSP.
- Added native resize cursor handling for all eight edges and corners with CSS fallback.
- Kept expanded pill content inside the active monitor work area at screen edges and corners.

### Reliability and lifecycle

- **#48 — transcription timeout and cancellation:** configurable deadline (default 900 s,
  30–1800 s bounds), user-visible cancel during Processing, process-group termination,
  shutdown-aware cancellation.
- **#50 — prepare-stop race:** generation-based pending-start ownership; stop during Preparing
  invalidates and succeeds; late workers discard without installing; shutdown invalidates.
- **#51 — shutdown child reaping:** recorder in its own process group; SIGINT then
  group-SIGKILL sweep on stop and graceful exit; reap on every path (PR #58 path preserved).
- **Transactional insertion stabilization (#36 subset):** 2-second paste-helper timeout with
  kill/reap, serialized clipboard transactions, clipboard restore on failed insertion,
  structured insertion reports, safe defaults for legacy history.

### Privacy and native boundaries

- **#47 — artifact ownership:** per-process `recording-<pid>-<uuid>` names, conservative
  stale-age reconciliation, live files never deleted, `0700` workspace, startup reclaim.
- **#52 — safe opener:** native `open_url`, strict canonical URL allow-list, no shell.
- **#53 — Unicode dictionary:** folded-char ranges from `char_indices`, no byte offsets from
  transformed strings.
- **#54 — clear history:** clears active+backup, removes only `history.corrupt-*.json`,
  actionable errors.

### Supply chain and release

- **#55:** SHA-pinned Actions, least-privilege permissions, no manual dispatch, fail-closed
  version/tag consistency with bare-`v` guard, protected-ref + `release` environment gates.
- **#56:** minimal dependency bumps; zero high-severity npm findings.
- **#41 (installer-integrity subset only):** pinned whisper commit + model revision, SHA-256
  verification, custom-model digest requirement, case normalization, verify-before-activate
  staging, Bash/PowerShell parity.
