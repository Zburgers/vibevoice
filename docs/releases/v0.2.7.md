# VibeVoice 0.2.7

## Change hierarchy

### Reliability and UX

- **#15 — UI text and icons disappear after transcription:** stale renderer refreshes can no longer overwrite newer state; async listener registration is cleaned up safely; repeated pill transitions have regression coverage.
- **Pill HUD edge/corner overflow:** expansion now chooses a safe monitor work area, moves before resizing, reconciles against native outer dimensions, and ignores stale layout requests.
- **Resize cursor defect:** all eight resize edges/corners set native cursor icons with CSS fallback.
- **Transactional insertion timeout cleanup:** paste helpers are bounded and reaped; insertion snapshots/restores the previous clipboard, serializes clipboard mutations, records structured outcomes, and keeps legacy history readable.

### Updates and diagnostics

- **#34 — SemVer precedence for updater fallback:** validated SemVer comparison handles prereleases, build metadata, `v` prefixes, and malformed values fail closed.
- **#8 — Copy diagnostics report:** adds a typed, categorized, redacted report that excludes transcripts, history, clipboard text, vocabulary, and raw errors.

### Security and packaging

- **#33 — CSP and pill capability isolation:** separates `main` and `pill` capabilities, removes `core:default`, authorizes commands by caller window, and configures packaged CSP.
- Updates application, Tauri, and release metadata to `0.2.7`, with frontend and Rust regression coverage.

## Stabilization

- Hardened renderer state refreshes so late responses cannot replace newer visible content.
- Added regression coverage for repeated state transitions and pill expand/collapse behavior.
- Replaced numeric update checks with validated SemVer precedence, including prereleases, build metadata, `v` prefixes, and malformed tags.
- Added a redacted diagnostics report that excludes transcripts, history, clipboard data, project vocabulary, and raw updater errors.
- Split main and pill capabilities, removed `core:default`, added caller-window authorization, and enabled a restrictive packaged CSP.
- Added native resize cursor handling for all eight edges and corners with CSS fallback.
- Kept expanded pill content inside the active monitor work area at screen edges and corners.
