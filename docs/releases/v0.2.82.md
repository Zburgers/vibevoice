# VibeVoice 0.2.82

Version: **0.2.82**. This hotfix follows 0.2.81 with safer handling of repeated recording controls.

<!-- release-notes:start -->
VibeVoice 0.2.82 makes recording stop and cancellation requests race tolerant, while carrying forward the Windows insertion recovery, floating pill Copy action, and dependency fix from 0.2.81.

## Fixes

- Treat repeated Stop requests after startup cancellation, during transcription, or after a session has already ended as harmless no-ops. Preserve the current state and transcript instead of showing a spurious error.
- Treat Cancel requests that arrive after transcription has claimed its result for insertion as harmless, while cancellation before that boundary still stops transcription.
- On Windows, type completed transcripts through Unicode input when rich clipboard formats cannot safely be restored, without changing the clipboard.
- Warn when Windows reports that only part of a transcript was typed, and tell users not to retry to avoid duplicate text.
- Add a Copy action beside the latest transcript in the floating pill.
- Update the affected transitive frontend dependency to a patched version so the high severity npm advisory no longer blocks release validation.
