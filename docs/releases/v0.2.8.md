# VibeVoice 0.2.8 — draft patch notes

Status: unreleased. These notes grow as changes are added to `codex/v0.2.8`.

## Clipboard recovery after successful transcription

Validation details: [clipboard-recovery evidence](../verification/v0.2.8-clipboard-recovery.txt).

- Fixed Windows auto-paste failing when the previous clipboard was empty or contained an image. Save/restore text, image pixels, or verified empty state; unsupported formats remain untouched with recovery guidance.
- Keep the existing transcript in the expanded pill when insertion fails. The control-page PR separately keeps transcript text and errors visible together.
- Three backend regressions verify snapshot selection and restoration after successful or failed paste. The reported error is after transcription, not evidence of a transcription race.

## Improvements

- **Revamped floating pill:** a compact status capsule expands into a single rounded menu with Record/Stop/Cancel/Retry, Paste, and Open App controls.
- **Readable transcripts:** the expanded menu keeps its controls visible while long transcripts scroll within their own area.

## Control page and transcript recovery

Validation details: [control-design evidence](../verification/v0.2.8-control-design.txt).

- Fixed status text escaping a circular badge by limiting rail badge sizing to the sidebar.
- Refined voice-session controls, shortcuts, recording duration, setup indicators, transcript actions, and narrow-window navigation.
- Kept completed transcript text visible beside insertion errors and offered copy/retry recovery without asking users to record again.
- Added seven frontend regressions across the control page and transcript display. Prior rendered checks covered 49 state/width combinations and seven actual app widths.
- Review refinement: only insertion error alerts use the error color; successful transcript text retains its normal color.

## Fixes

- Fixed the expanded pill being clipped inside a small window or spilling outside its visible surface.
- Removed the native rectangular window shadow around the transparent pill host.
- Disabled image dragging, text selection, and browser context menus in the pill, including “Save image as” and “Copy image.” The move handle and expand/collapse controls remain available.

## Whisper transcription performance and reliability

Audit and measurements: [Whisper pipeline evidence](../verification/v0.2.8-whisper-performance.md).

- Added a transcription CPU thread limit and a passive-wait hint for supporting OpenMP runtimes, keeping the model, beam search, and fallback settings unchanged. Two threads used about 23% average CPU but took 5.97 seconds versus 4.68 seconds with the prior defaults on an 11-second sample. Small same-thread timing differences are preliminary and do not establish a speedup on Microsoft's runtime.
- Added actual audio/transcription durations and Windows Whisper CPU time, average CPU share, and peak memory to Diagnostics and its copyable support report.
- Fixed repeated Stop clearing Processing and admitting another session, and made late Cancel arbitrate with insertion so an acknowledged cancellation prevents clipboard/paste side effects.
- Finish microphone callbacks before closing the WAV writer; clean writer resources and temporary WAVs on preparation failure. Saved recording duration now measures audio frames rather than transcription/paste wall time.
- Identified the original engine as 1.8.6 and corrected source installer pins to checkout commits. The component update below advances the recommended engine to 1.9.4; separate engine and quantized-model trials do not establish an upgrade speedup or justify changing the default model for performance.
- Frontend production build, 20 frontend tests, 61 backend tests, strict Clippy, a real installed-CLI/resource measurement probe, and the optimized Windows build passed. The test EXE is available in `outputs/whisper-performance/`; owner microphone testing and full release qualification remain pending.

## Whisper engine and model updates

Validation details: [component updater evidence](../verification/v0.2.8-whisper-updater.md).

- Added separate **Update Whisper engine** and **Verify / repair model** controls in Settings and Diagnostics, including download progress and cancellation. These controls work in production builds without Git, CMake, or a compiler.
- Pin the recommended Whisper engine to 1.9.4 and verify the official Windows package by SHA-256 before extraction and a startup check. Updates activate a separate managed directory and keep the previous engine and custom model intact.
- Verify the existing base.en weights before downloading. Missing or corrupt default weights get a verified managed copy; the model action explicitly selects the default English model. Engine updates preserve the selected model.
- Serialize updates with recording and settings changes, reject duplicate operations, and retain the existing settings on cancellation or validation failure. Automatic engine downloads support Windows x64 and ARM64; model verification/repair works on all platforms.
- Updated both source setup scripts to the stable 1.9.4 checkout commit. The local engine was updated from 1.8.6 to 1.9.4; base.en was already current. Controlled short-sample timings do not establish a version-upgrade speedup.
