# VibeVoice 0.2.81

Version: **0.2.81**. This hotfix follows 0.2.8 and is intended for a reviewed release candidate.

<!-- release-notes:start -->
VibeVoice 0.2.81 fixes Windows transcript insertion when the system clipboard contains rich or application-specific formats, and makes transcript copying available directly in the floating pill.

## Fixes

- When Windows clipboard formats cannot be safely snapshotted and restored, type the completed transcript through Unicode keyboard input without replacing the clipboard.
- If Windows reports a partial keyboard-input send, warn that text may already have been inserted and tell users not to retry, avoiding duplicate text.
- Add a Copy action beside the latest transcript in the floating pill, so users can copy a completed transcript without opening the main window.
<!-- release-notes:end -->
